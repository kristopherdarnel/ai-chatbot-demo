# FAQ chatbot demo

A small, reconstructed technical sample for a portfolio. It demonstrates a browser chat widget, a Node.js HTTP API, input validation, and responses grounded in a fictional FAQ. It is not production customer code or an AI model.

## Run

Requires Node.js 18 or newer. Run `npm start`, then open `http://localhost:3000`. Run `npm test` for the checks.

The demo answers questions about hours, returns, and support. For other questions it declines to invent an answer. The FAQ contains fictional details only. No credentials, customer data, external services, or dependencies are required.
